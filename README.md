# ZDUNO Client

ZDUNO Client — это веб-приложение для проведения викторин с использованием React, Redux Toolkit и TailwindCSS.

## Стек технологий

- **React**: для построения пользовательского интерфейса.
- **Redux Toolkit**: для управления состоянием.
- **TypeScript**: для статической типизации.
- **Vite**: для сборки проекта.
- **TailwindCSS**: для стилизации.
- **React Router**: для маршрутизации.

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone <URL репозитория>
   cd ZDUNO_client
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите проект в режиме разработки:

   ```bash
   npm run dev
   ```

4. Для сборки проекта используйте:

   ```bash
   npm run build
   ```

5. Для предпросмотра собранного проекта:
   ```bash
   npm run preview
   ```

## Структура проекта

- **src/components**: Компоненты приложения.
- **src/features/questions**: Логика управления вопросами и ответы.
- **src/hooks**: Пользовательские хуки.
- **src/pages**: Страницы приложения.
- **src/router**: Настройка маршрутов.
- **src/store**: Конфигурация Redux Store.
- **src/types**: Типы TypeScript.
- **src/index.css**: Основные стили приложения.

## Основные возможности

- Поддержка различных типов вопросов:
  - Вопросы с одним вариантом ответа (radio button).
  - Вопросы с несколькими вариантами ответа (checkbox).
  - Вопросы с текстовым вводом.
- Таймер для ограничения времени на ответы.
- Подсчет правильных ответов.

## Скрипты

- `npm run dev`: Запуск проекта в режиме разработки.
- `npm run build`: Сборка проекта.
- `npm run preview`: Предпросмотр собранного проекта.
- `npm run lint`: Запуск линтера.
